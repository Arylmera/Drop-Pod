# AI, the reality check — Talk 1 of 4

## Context
Back-from-Devoxx-Belgium-2026 series "From chat to agents we can trust", presented every two weeks at the community of practice; this is talk 1 of 4, 30 minutes (20 slides), first of a 4-talk series.
Target: no code project — presentation material to open and present from the work machine.

## Decisions
- Self-contained HTML deck (works offline, no install): dark modern editor theme, rubber-duck progress marker, series map, "Previously" / "Next time" bridges.
- Improvisation mode: one talking-points card per slide (idea, points, example, transition, duration) instead of a script; no live demo, no homework.
- English; illustrative Java examples are marked as such; sources and hedges are in notes.md.

## Apply
1. Open `deck.html` in a browser (double-click). F = fullscreen, → / Space / clicker = next, ← = previous, O = overview.
2. Press S to open the presenter window: current slide's talking-points card, next slide, 25-min timer (R resets). The main window follows it.
3. Before the session, read `notes.md` (goal, thesis, timed run-through, facts and sources, likely Q&A) and do one timed read-through with `talk-points.md`.
4. Ctrl+P exports the deck to PDF, one slide per page, if a PDF is needed.

## Files
- deck.html — the slide deck (20 slides), self-contained
- talk-points.md — one talking-points card per slide (also shown in the presenter window)
- notes.md — preparation notes: goal, thesis, timing, facts with sources, Q&A, council debate
