Who guards the guard?

A hook inside the agent
  • Runs before or after a tool call
  • Deterministic code, not AI
  • Agents are good at finding the one path it doesn't cover
The build, run outside it
  • A failing Maven build, or a CI job on the server
  • Runs on the result, whoever produced it
  • Not skippable with a local --no-verify
  • Config protected by CODEOWNERS, changed only with a human sign-off

Silence is not a result

1Output contract

OK, OUT_OF_SCOPE or ERROR — never an invented answer dressed up as a result.

2Guardrails

Hard limits stated plainly: never raw SQL, never a card number, always the declared shape.

3Deterministic hooks

PreToolUse blocks, PostToolUse formats and tests — code, not another model's judgment.

“A non-PASS result must never hide another independent finding. Silence is not a pass.” — JI Darwish, Devoxx Belgium 2026

The loop, bounded

1Gate

Compile first. Fails → everything else SKIPPED, stop.

2Focused checks

Lint, business rules, architecture — all run, none hides another.

3Full suite

The expensive one, only once everything cheaper is green.

4One repair

A single prompt: the policy, plus every finding, compact — not a log dump.

5Fresh verdict

Re-verify everything on the final source. Still red → a human decides.

Would this harness have caught it?

1Rules

Could the agent edit the check that measured it? No — the rule lived in the build, not in a prompt it could talk around.

2Evidence

Did the test come from outside the agent? No, in the original story — and that's exactly where it failed.

3Verdict

Would a fresh verdict, re-run on the final file, have caught a hard-coded row count? Yes — a real parser check doesn't pass on a filename match.

Key takeaways

  1. 1A rule the agent can negotiate is a suggestion — put it in the build, where the agent can't edit the check.
  2. 2Evidence has to come from outside the agent: independent tests, a status it can't fake, a stage that never goes silent.
  3. 3One bounded repair, then a fresh verdict on the final source. Past that, a human decides.
