# The harness around the agent — Talk 2 of 4

## Context
Back-from-Devoxx-Belgium-2026 series "From chat to agents we can trust", presented every two weeks at the community of practice; this is talk 2 of 4 (22 slides), follows 2026-10-13-devoxx-talk-1-ai-reality-check. Flexible length, 10 to 20 minutes.
Target: no code project — presentation material to open and present from the work machine.

## Decisions
- Self-contained HTML deck (works offline, no install): dark modern editor theme, rubber-duck progress marker, series map, "Previously" / "Next time" bridges.
- Spoken speaker text, same format as talk 1 (2026-10-28, replaces improvisation cards): per slide a bold fil rouge line, the outline, the full text to read aloud in a conversational tone, a transition; key words highlighted in yellow. No live demo, no homework.
- Two routes: CORE slides make the ~10-min short route (IF TIME slides get one "Short route" line or are skipped); everything is ~20 min.
- Merged: "encode the same wrong idea twice" into slide 12, the Darwish "silence is not a pass" quote into slide 14.
- English; illustrative Java examples are marked as such; sources and hedges are in notes.md.

## Apply
1. Open `deck.html` in a browser (double-click). F = fullscreen, → / Space / clicker = next, ← = previous, O = overview.
2. Press S to open the presenter window and drag it to the second screen: speaker text, next slide, elapsed timer (R resets). Drive the talk from the presenter window; the deck window follows it. In the call, share only the deck window, not the whole screen.
3. Before the session, read `notes.md` (facts, sources, likely Q&A; its timing table and slide numbers predate the 22-slide format) and do one read-through. If the presenter window misbehaves, open `talk-points.md` on the second screen instead: same text.
4. Ctrl+P exports the deck to PDF, one slide per page, if a PDF is needed.

## Files
- deck.html — the slide deck (22 slides), self-contained
- talk-points.md — the same speaker text as the presenter window, one card per slide (fallback for the second screen)
- notes.md — preparation notes: goal, thesis, timing, facts with sources, Q&A, council debate
